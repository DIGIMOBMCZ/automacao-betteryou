Política de Privacidade

Esta Política de Privacidade descreve como o aplicativo N8N DIGIMOB utiliza informações necessárias para execução de suas automações internas.

1. Finalidade

O N8N DIGIMOB é utilizado para automações operacionais e administrativas, incluindo monitoramento de serviços e envio de notificações por e-mail.

2. Integração com o Google

Quando autorizado pelo usuário, o aplicativo pode utilizar serviços Google para executar funcionalidades específicas, como o envio automatizado de e-mails operacionais.

O acesso é utilizado exclusivamente para executar as funções autorizadas pelo usuário.

3. Uso das informações

As informações acessadas através das integrações são utilizadas somente para a execução das automações configuradas no aplicativo.

Os dados obtidos através das APIs do Google não são vendidos para terceiros nem utilizados para publicidade.

4. Compartilhamento de dados

O aplicativo não comercializa informações pessoais obtidas através das integrações utilizadas.

5. Segurança

São adotadas medidas técnicas e operacionais destinadas a restringir o acesso às credenciais e informações utilizadas pelas automações.

6. Revogação de acesso

O usuário pode revogar as permissões concedidas ao aplicativo através das configurações de segurança da sua Conta Google.

7. Contato

Em caso de dúvidas relacionadas a esta Política de Privacidade, entre em contato pelo e-mail: digimobmcz@gmail.com.

8. Atualizações

Esta Política de Privacidade poderá ser atualizada para refletir alterações nas funcionalidades ou integrações utilizadas pelo aplicativo.
